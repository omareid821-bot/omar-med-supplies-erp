# مشروع: omar-med-supplies-erp

نظام ERP لإدارة المستلزمات الطبية (واجهة عربية RTL - PWA)

ملخص سريع:
- واجهة كاملة باللغة العربية (RTL)
- PWA مدعوم
- مبدئياً تم تضمين بيانات تجريبية للبدء بالاختبار
- إعدادات Supabase: ملف SQL لإنشاء الجداول الأساسية موجود في supabase/init.sql

كيفية التشغيل المحلي:
1. تثبيت الحزم: npm install
2. تشغيل التطوير: npm run dev
3. للوصول إلى بيانات العينة: افتح /api/seed

بيانات الدخول الاختبارية:
- مشرف (Admin): admin@example.com
- مندوب مبيعات: rep@example.com
